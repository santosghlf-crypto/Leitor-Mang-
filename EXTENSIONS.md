# Koma 6.0 — GUT 5: perfis de extensão
Cada fonte pode ter um perfil declarativo separado, sem alterar seus cookies, bloqueios ou dados da biblioteca. Use Fontes > opções > Configurar extensão. Existem modelos genérico, Madara e MangaReader; são pontos de partida, não garantias de compatibilidade com todos os sites. Edite seletores para adaptar.
Campos: version=1, name, reader (contêiner de imagens), next, previous, title, chapterLabel, workLink, catalog e chapters. Links podem ser âncoras ou contêineres com uma âncora. Use tags, classes, IDs e até quatro segmentos simples separados por espaço ou >. Não há JavaScript importável, URLs de rede, HTML, curingas, seletores de atributo, pseudo-classes ou expressões regulares. JSON de até 4096 caracteres, importação revisada pelo usuário e exportação via área de transferência.
No leitor: menu > Explorar catálogo, Listar capítulos ou Salvar obra detectada. A leitura do DOM acontece na página já carregada pelo Gecko, somente mediante solicitação; até 100 links, com 300 elementos examinados. Links externos/inseguros são rejeitados pelo script e novamente pelo código nativo. Nome de capítulo pode ser preenchido automaticamente por seletor configurado para uma obra vinculada. Salvar obra abre formulário de confirmação. Não há busca universal entre sites, coleta em segundo plano ou download de capas remotas nesta etapa.
O perfil genérico preserva os leitores reconhecidos previamente; catálogo/lista requer seletor configurado. Se um site usa navegação dinâmica incompatível ou APIs próprias, pode exigir configuração adicional ou navegação manual. Não há promessa de suporte universal. Testes Node e JVM cobrem validação e extração, não substituem teste no Android com os sites reais.
