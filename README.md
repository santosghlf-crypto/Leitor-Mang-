# Koma
Leitor Android ARM64 com GeckoView e uBlock Origin.

Para gerar o APK, abra Actions → Gerar APK. Baixe o artefato Koma-Android-arm64 e extraia app-debug.apk.

Android 8 ou superior. Adicione sites HTTPS na estante. Use Voltar para mostrar os controles de leitura.

Componentes: Mozilla GeckoView (MPL-2.0), uBlock Origin (GPL-3.0), https://github.com/gorhill/uBlock.
